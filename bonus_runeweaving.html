The Runeweaver's Atelier

Long before wands drew windows, weavers drew pictures out of nothing but characters. Typewriter artists were doing it in 1898. Today the Atelier opens, and you learn the old craft: shapes from spaces, stars, and loops.

Chunks explored
Chunk 1 · Threads of the loom

Repeat anything; pad with space

The repeat charm works on any text, and the most important character it repeats is the invisible one. A space is a real stitch. Build this three-line hat by hand, no loop yet.

print("*" * 5)
print("Go! " * 3)
print(" " * 2 + "*")
print(" " * 1 + "***")
print("*****")
Predict Line 2: what exactly prints, and is there anything after the last exclamation mark? Lines 3 to 5: why do the space counts go 2, 1, 0?
Go! Go! Go! prints with a trailing space you can't see, because the space inside the quotes repeats too. And the space counts shrink by one as the stars grow by two, which keeps the tip over the middle. Hold that thought; it becomes a formula in Chunk 4.

Chunk 2 · Up the stairs, down the stairsE5-PRO-VD-?? ⚠

range can count backward

You know the staircase up. A step of -1 weaves it back down: range(5, 0, -1) deals 5, 4, 3, 2, 1.

for row in range(1, 6):
    print("*" * row)
for row in range(5, 0, -1):
    print("*" * row)
Predict How many lines print in total? The widest row appears twice, back to back. Which one change to the second loop would fix that?
Ten lines, and rows of five stars sit at lines 5 and 6. Start the second loop at range(4, 0, -1) and the peak appears once. The third number in range is the step: how far, and in which direction, each pass moves.

Chunk 3 · The right-leaning stair5.OA.B.3

Two rules per row: spaces, then stars

Push the staircase against the right wall. Each row obeys two rules at once: n - row spaces, then row stars.

n = 5
for row in range(1, n + 1):
    print(" " * (n - row) + "*" * row)
Predict For row 2, how many spaces and how many stars? Fill the Grimoire pairs table: (row, spaces, stars) for all five rows.
Row 2 gets 3 spaces and 2 stars. The full table: (1, 4, 1), (2, 3, 2), (3, 2, 3), (4, 1, 4), (5, 0, 5). As one pattern climbs, the other falls, and their sum is always 5, which is why the right edge stays flat. Two rules, corresponding terms, drawn instead of graphed.

Chunk 4 · The wizard's hat5.OA.B.3

The centered pyramid: n - row and 2*row - 1

Chunk 1's hand-built hat becomes a formula. Spaces: n - row. Stars: 2 * row - 1, always an odd number, which is what keeps the hat symmetric. Two lines after the loop give it a stand.

n = 5
for row in range(1, n + 1):
    print(" " * (n - row) + "*" * (2 * row - 1))
print(" " * (n - 1) + "|")
print(" " * (n - 1) + "|")
Predict Write the star counts for rows 1 to 5. Why must every row have an odd number of stars? And why does the stand use n - 1 spaces?
1, 3, 5, 7, 9. An odd width has a single middle star, so every row can center on the same column; an even row has no middle and the hat tilts. The stand uses n - 1 spaces because that's exactly where the tip's column is: the same rule that placed row 1. Change every * count's rule and the hat becomes a tree, a tent, a mountain. The rules are the picture.

Chunk 5 · The diamond5.OA.B.3

A pyramid and its reflection

Chunk 2's trick meets Chunk 4's formula: weave the hat, then weave it again counting down, starting one row early so the peak appears once.

n = 4
for row in range(1, n + 1):
    print(" " * (n - row) + "*" * (2 * row - 1))
for row in range(n - 1, 0, -1):
    print(" " * (n - row) + "*" * (2 * row - 1))
Predict How many lines in the whole diamond? Which row prints the seven-star line, and how many times does it appear?
Seven lines: four up, three down. The seven-star line is row 4, the widest, and it appears exactly once because the second loop starts at n - 1. Cover the second loop with your finger and read the first alone; every hard shape today is easy shapes stacked.

Chunk 6 · Two ways to weave a rowE5-PRO-PD-?? ⚠

end="" against the accumulator

Until now, one print made one row. Inside a nested loop there's a choice. Way 1: print("#", end="") tells print to stay on the line, and a bare print() ends the row. Way 2: gather the row in a vessel first, Day 2's accumulator, then print it once. Run both.

# Way 1: end="" stitches sideways
for row in range(3):
    for col in range(5):
        print("#", end="")
    print()

# Way 2: the accumulator weaves the row first
for row in range(1, 5):
    row_text = ""
    for col in range(row):
        row_text = row_text + "*"
    print(row_text)
Predict Way 1: what happens if you delete the bare print()? Way 2: what happens if row_text = "" moves above the outer loop?
Delete the bare print() and all fifteen # marks collapse onto one line; nothing ever says "row over." Move the reset out of the loop and the vessel never empties, so the staircase becomes 1, 3, 6, 10 stars, each row dragging the last one along. Both are famous misfires. Pick the way you can trace: the accumulator has one fewer moving part, and end="" is the sleeker stitch once you trust it.

Chunk 7 · The hollow vaultE5-PRO-RD-?? ⚠

or: a gate with four ways to say yes

Draw only the walls. The word or chains questions into one flat gate: the door opens if any one answer is yes. Edges are where row or column is first or last.

rows = 5
cols = 8
for row in range(rows):
    for col in range(cols):
        if row == 0 or row == rows - 1 or col == 0 or col == cols - 1:
            print("#", end="")
        else:
            print(" ", end="")
    print()
Predict Which cells print #: the middle, the edges, or everything? For the cell at row 2, col 3, which of the four questions are yes?
Only the edges. At row 2, col 3, all four questions answer no (2 isn't 0 or 4, 3 isn't 0 or 7), so the gate falls through to the space. One flat gate, four questions, and or is today's first new word: it never nests, it chains.

Chunk 8 · The checkered floorE5-PRO-RD-?? ⚠

%: the remainder mark

Today's second new mark: % gives the remainder after dividing. (row + col) % 2 is 0 on even squares and 1 on odd ones, and it flips with every step in any direction. That flip is a checkerboard.

for row in range(4):
    for col in range(8):
        if (row + col) % 2 == 0:
            print("#", end="")
        else:
            print(" ", end="")
    print()
Predict Does the first square of row 0 print # or space? What about the first square of row 1, and why do neighboring rows start differently?
Row 0 starts with # because 0 + 0 leaves remainder 0. Row 1 starts with a space because 1 + 0 leaves remainder 1. Each new row shifts the sum by one, so the whole pattern slides sideways, and that slide is the checkering. One small honest note: rows that end on a space really do end on a space; it's an invisible stitch, not a mistake.

Hinge question · stop here until you're sure5.OA.B.3

Row four of the six-row hat

A wizard's hat is woven with n = 6.
On row 4, how many spaces are stitched, and how many stars?

Two spaces and seven stars. Spaces: 6 − 4. Stars: 2 × 4 − 1. If you reached for the code instead of the rules, weave the pairs table for all six rows before the build; the Atelier's whole craft is being able to say a row before you see it.
Build brief · The Illuminated Page

One page, four woven bands

Build an Illuminated Page program that weaves, top to bottom:

1. A border band with the repeat charm.
2. A wizard's hat sized by input() and int(), rows 3 to 8, on its stand.
3. Your own small creature or crest stored as a list of strings, printed with for line in art:.
4. A two-row checkered floor, then an f-string signature and the closing border.

One craft note for band 3: to put a real backslash in a string, write two: "\\" prints one \. Every slanted roof needs it.

Suggested start: borders first, hat second, one band per run. House law: one change per run.

print("=" * 24)
name = input("Runeweaver's name: ")
rows = int(input("Hat size (3 to 8): "))

# --- the hat ---
for row in range(1, rows + 1):
    print(" " * (rows - row) + "*" * (2 * row - 1))
print(" " * (rows - 1) + "|")

# --- the crest ---
crest = [
    "  /\\  ",
    " /  \\ ",
    "/ ** \\",
    "------",
]
for line in crest:
    print(line)

# --- the floor and the signature ---
for row in range(2):
    for col in range(12):
        if (row + col) % 2 == 0:
            print("#", end="")
        else:
            print(" ", end="")
    print()
print(f"Woven by {name}.")
print("=" * 24)
Your crest should be yours: a cat, a key, a crescent, anything you can stitch in four or five short lines. The page is a portfolio of every pattern in the Atelier.
