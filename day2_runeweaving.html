Chunk 1 · The repeat charm

One rune, five times

Yesterday * tripped you in the text trap — text times a number repeats the text. Today that trap becomes your loom. Run:

print("✦" * 5)
Predict Exactly what appears — five runes, the number 5, or a misfire? Write your guess, then run.
Five runes in a row. "✦" * 5 means this exact text, repeated 5 times. Yesterday's trap, today's tool — the wand never changed; your intent did.

Chunk 2 · Meet the loomE5-PRO-RD-?? ⚠

for and range — the counting charm

A loop repeats your indented lines. range(4) deals out the numbers 0, 1, 2, 3 — and row catches a new one each pass.

for row in range(4):
    print("row", row)
Predict How many lines will print? What is the first number — and what is the last? Trace it on your Grimoire sheet: one row per pass.
Four lines. It starts at 0 and ends at 3 — range(4) means four numbers, starting from 0, so 4 itself never arrives. The vessel row is refilled each pass: 0, then 1, then 2, then 3.

Chunk 3 · The rule weaves5.OA.B.3

A changing rule makes a shape

Now hand the loop's number to the repeat charm. The rule is "✦" * row — and row changes every pass.

for row in range(1, 6):
    print("✦" * row)
Predict Sketch the shape on your Grimoire sheet before you run — every row, exactly. Where does range(1, 6) start, and where does it stop?
A staircase of runes, 1 to 5. range(1, 6) starts at 1 and stops before 6. One small rule, five rows of pattern — that's the whole secret of the Loom Hall.

Chunk 4 · Read it, trace it, then run itE5-PRO-RD-?? ⚠

Wall or weave? The rule decides

Same loom, different rule. Read this without running it and decide what it builds.

for row in range(4):
    print("=" * 8)
Predict Chunk 3 grew wider every row. Will this one? Say what makes the difference — then run to check yourself.
A solid wall: four identical rows of eight. The rule "=" * 8 never mentions row, so nothing changes between passes. Constant rule = wall. Changing rule = weave. Being able to say that before running is what makes you a reader of code, not just a runner of it.

Chunk 5 · Two rules, one loom5.OA.B.3

Corresponding patterns — the numbered tapestry

Print two patterns side by side each pass: the row number, and that many runes. Two rules, moving together.

for row in range(1, 5):
    print(row, "✦" * row)
Predict Write all four lines exactly. Then fill the ordered-pairs table on your Grimoire sheet: (row, number of runes) for every pass. What is the relationship between the two?
The pairs are (1, 1), (2, 2), (3, 3), (4, 4) — the rune count equals the row number, because both patterns come from the same vessel. Change the rule to "✦" * (row + row) and the pairs become (1, 2), (2, 4), (3, 6), (4, 8): the second pattern is double the first. Two rules, corresponding terms — you just did fifth-grade pattern math on a loom.

Chunk 6 · Enchanted ink

Fetch the ink: rich

In the VS Code terminal (not your file), run pip install rich once. Then, at the very top of day2.py, swap in the enchanted printer and paint:

from rich import print

print("[bold yellow]The Loom of the Academy[/bold yellow]")
for row in range(3):
    print("[magenta]✦ ✦ ✦ ✦ ✦ ✦[/magenta]")
Predict Will the square brackets and the word magenta appear in the terminal — or vanish? What will you see instead?
They vanish. The bracket tags are instructions to the ink, the way quotes are instructions to the wand: [magenta]…[/magenta] means tint everything between us. The first line glows gold-yellow; the three woven bands glow magenta. The from rich import print line trades your plain printer for an enchanted one — today only, and only in files where you ask for it.

Chunk 7 · The missing rowE5-PRO-RD-?? ⚠

Misfire on purpose: the off-by-one

An apprentice wants a four-row staircase and writes this. Read it first. Something is short.

for row in range(1, 4):
    print("✦" * row)
Predict How many rows will actually weave — and which row is missing? Say why before you run.
Three rows — the four-rune row never weaves, because range(1, 4) stops before 4. This is the most famous misfire in all of programming, the off-by-one. The counter-curse: to reach the number you want, write one past it — range(1, 5).

Chunk 8 · Looms in sequenceE5-PRO-PD-?? ⚠

Stack two looms

Loops obey Day 1's first law — one line at a time. A second loop simply waits its turn.

for row in range(3):
    print("= = = = = =")
for row in range(1, 6):
    print("✦" * row)
Predict How many lines print in total? Which finishes completely first — and could they ever interleave?
Eight lines: the banner weaves all three of its rows, then the staircase weaves its five. Loops never interleave on their own — the first must finish before the second begins, because the wand still reads top to bottom.

The four-line prophecy

Without running it: for row in range(2, 6): print("✦" * row)
How many lines weave — and how many runes are on the last line?

Four lines, and the last holds five runes. range(2, 6) deals 2, 3, 4, 5 — starts at the first number, stops before the second. If you said "five lines" or "six runes," re-trace Chunks 2 and 7 before the build. If you got both, the Loom Hall is yours.
Build brief · The Grand Tapestry

Weave a tapestry to order

Build a Grand Tapestry program that:

1. Prints a crown band — a short loop of a rich-tinted banner line.
2. Asks the weaver's name with input().
3. Asks how many rows to weave, converting with int().
4. Weaves a numbered staircase with two corresponding patterns: print(row, "✦" * row).
5. Signs the work with an f-string: name and row count.

Useful pieces: for · range(1, rows + 1) · "✦" * row · from rich import print · f"..."

Suggested start: weave a fixed 5-row staircase first. Only then swap the 5 for the asked-for number. House law: one change per run.

# --- Crown band ---
from rich import print

for row in range(3):
    print("[bold yellow]= = = = = = = =[/bold yellow]")

# --- The tapestry ---
name = input("Weaver's name: ")
rows = int(input("How many rows? "))
for row in range(1, rows + 1):
    print(row, "✦" * row)
print(f"Woven by {name}: {rows} rows complete.")
Notice range(1, rows + 1) — the counter-curse from Chunk 7, cast on purpose so the last row actually arrives.

Choose your exit gate

Floor · approaching the standard

You weave a fixed five-row staircase from the single rule "✦" * row, and you can point to the line where the rule lives.

Middle · meets the standard

Your Grand Tapestry weaves any asked-for number of rows with the numbered two-pattern rule — and your Grimoire ordered-pairs table is complete, with the relationship between the two patterns written in your own words.

Stretch · exceeds the standard

Add the reflection: a second loom, for row in range(rows, 0, -1), weaving the staircase back down into a diamond. Then answer in your Grimoire: why does the widest row appear twice, and what one change would fix it?
