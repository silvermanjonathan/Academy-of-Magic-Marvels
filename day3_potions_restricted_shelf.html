Chunks explored
Chunk 1 · The brewing gateE5-PRO-RD-?? ⚠

if — run this only when it's true

An if line asks a yes-or-no question. The indented line below it runs only when the answer is yes.

temp = 80
if temp > 75:
    print("The cauldron glows ember-bright.")
Predict Will the glow line print? Now change temp to 60 and predict again before the second run.
At 80 it prints — the question temp > 75 is true. At 60 the program prints nothing at all and ends quietly: a false if simply skips its indented lines. Silence is an answer too.
You should see (with temp = 80) 
The cauldron glows ember-bright.
Chunk 2 · The other doorE5-PRO-RD-?? ⚠

else — when the answer is no

A gate with one door leaves people standing outside. else is the other door — no question of its own, it simply catches every "no."

temp = 60
if temp > 75:
    print("The cauldron glows.")
else:
    print("The brew sleeps. Add more flame.")
Predict Which one line prints at 60? Could both lines ever print on the same run? Commit, then test both temperatures.
At 60, the sleeping line. And no — exactly one door ever opens per run. if/else is a fork in the corridor, not a checklist.
You should see (with temp = 60) 
The brew sleeps. Add more flame.
Chunk 3 · Three doors, flatE5-PRO-RD-?? ⚠

elif — the middle door

Three outcomes, one flat ladder — the wand checks each question in order and takes the first true door.

temp = 90
if temp < 50:
    print("Too cold: the brew crystallizes.")
elif temp > 85:
    print("Scorching: stand back!")
else:
    print("Steady heat. Keep stirring.")
Predict At 90: how many of the three lines print, and which one? What about at exactly 85?
Exactly one line, always. At 90 it's Scorching. At 85 the first question is false (85 is not less than 50), the second is false too (85 is not greater than 85) — so the else door opens: Steady heat. Notice the ladder stays flat: three doors side by side, no door hiding inside another door. That's Academy style.
You should see (with temp = 90) 
Scorching: stand back!
Chunk 4 · The shelfE5-PRO-VD-?? ⚠

A list — one vessel, many flasks

Yesterday's vessels held one value each. A list is a shelf of flasks, and every flask has a number. The numbering starts at 0.

shelf = ["moonpetal", "ashroot", "dewbark"]
print(shelf[0])
print(shelf[2])
Predict Two lines will print. Which ingredient comes out of flask 0 — and which out of flask 2? Label the shelf on your Grimoire sheet: number under each flask.
moonpetal then dewbark. Flask 0 is the first flask — the shelf counts 0, 1, 2. It feels wrong for exactly one day, and then it feels like the only sensible way to count.
You should see 
moonpetal
dewbark
Chunk 5 · Count the flasks, then reach too farE5-PRO-VD-?? ⚠

len() — and a misfire on purpose

len(shelf) counts the flasks. Then reach for a flask that isn't there, on purpose, and read the smoke.

shelf = ["moonpetal", "ashroot", "dewbark"]
print(len(shelf))
print(shelf[3])
Predict What number does len report? And flask 3 — is that the last ingredient, or a misfire? Why?
len reports 3 — but the flasks are numbered 0, 1, 2, so flask 3 doesn't exist and the wand misfires. On a 3-flask shelf, the last flask is number 2: the last number is always one less than the count. That's Chunk 7's off-by-one, back for a second visit.
You should see (last line of the traceback) 
IndexError: list index out of range
Chunk 6 · Walk the shelfE5-PRO-VD-?? ⚠

The loop visits every flask

Yesterday for counted numbers. It can also walk a shelf — the vessel ingredient is refilled with each flask in turn.

shelf = ["moonpetal", "ashroot", "dewbark"]
for ingredient in shelf:
    print("Fetch", ingredient)
Predict How many lines print, and in what order? Could the loop ever skip a flask or shuffle the order on its own?
Three lines, in shelf order, every time. for ingredient in shelf means visit each flask once, left to right — no skipping, no shuffling. Shuffling is the cauldron's job, and that's next.

Fetch moonpetal
Fetch ashroot
Fetch dewbark
Chunk 7 · The choosing cauldronE5-PRO-VD-?? ⚠

random.choice — the cauldron picks a flask

Import the chance-magic once, at the top of the file. Then let the cauldron choose. Run this three times.

import random

shelf = ["moonpetal", "ashroot", "dewbark"]
pick = random.choice(shelf)
print("The cauldron chooses:", pick)
Predict What lands in the vessel pick — an ingredient, or a flask number? Across three runs, could the cauldron choose the same ingredient twice?
An ingredient — random.choice hands you the item itself, never its number. And yes, it can absolutely repeat: each run is a fresh, forgetful choice. If your three runs matched twice, the cauldron isn't broken — that's what chance looks like.
You should see (one of these, per run) 
The cauldron chooses: moonpetal

Chunk 8 · The Restricted Shelf gateE5-PRO-RD-?? ⚠

in — is it on the shelf?

The word in asks the shelf a yes-or-no question — which makes it perfect fuel for a gate.

shelf = ["moonpetal", "ashroot", "dewbark"]
ask = input("Which ingredient do you seek? ")
if ask in shelf:
    print("Fetch it from the open shelf.")
else:
    print("The Restricted Shelf stays sealed.")
Predict Run it twice: once asking for ashroot, once for gloomvine. Which door opens each time? What would typing Ashroot with a capital A do?
ashroot opens the shelf; gloomvine hits the sealed door. And Ashroot stays sealed too — the wand matches letters exactly, and a capital A is a different letter. Literal-mindedness, Day 1's motto, guarding a shelf.
You should see (two runs) 
Which ingredient do you seek? ashroot
Fetch it from the open shelf.

Which ingredient do you seek? gloomvine
The Restricted Shelf stays sealed.

The fourth flask

A shelf holds ["nettle", "sage", "fernroot"].
What does shelf[1] print — and what happens on shelf[3]?

shelf[1] is sage — flask 0 is nettle, flask 1 is sage. And shelf[3] misfires with an IndexError: three flasks means the numbers stop at 2. If you said "fernroot" for either, re-walk Chunks 4 and 5 before the build. If you got both, the Vault is yours.
Build brief · The Stockroom Gatekeeper

Guard the shelf, gift the brave

Build a Stockroom Gatekeeper program that:

1. Keeps a shelf of at least four ingredients in one list.
2. Prints the stockroom seal, then asks the apprentice's name.
3. Asks which ingredient they seek.
4. If it's on the shelf: grants it — and has the cauldron random.choice a bonus gift.
5. Otherwise: the Restricted Shelf stays sealed, by name, in one f-string.

Useful pieces: if / else · in · random.choice() · input() · f"..." · a flat gate — no door inside a door.

Suggested start: shelf and seal first, gate second, cauldron gift last. House law: one change per run.

import random

shelf = ["moonpetal", "ashroot", "dewbark", "silverleaf"]

print("=== THE ACADEMY STOCKROOM ===")
name = input("Apprentice name: ")
ask = input("Which ingredient do you seek? ")

if ask in shelf:
    bonus = random.choice(shelf)
    print(f"Granted, {name}. Fetch the {ask}.")
    print(f"The cauldron adds a gift: {bonus}.")
else:
    print(f"Denied, {name}. The Restricted Shelf stays sealed.")
One flat gate, two doors, and the cauldron only stirs on the granted path. Yours doesn't have to match — it has to run, and you have to be able to trace it.
